# Harmonização dos estoques de COS para 0–30 cm

Esta pasta contém o script `harmonizacao_COS_0_30.R`, versão 1.0.4.

O código realiza a auditoria da base, seleciona a origem válida do estoque, resolve duplicidades, harmoniza os valores para 0–30 cm, calcula os fatores empíricos, classifica a incerteza procedimental, consolida P89 e gera tabelas de controle.

A interpolação entre estoques acumulados não integra esta versão porque não foi aplicada a nenhum perfil da base analisada.
